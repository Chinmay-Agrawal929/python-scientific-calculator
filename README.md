# 🧮 Python Scientific Calculator

A robust, menu-driven command-line scientific calculator built in Python. It handles basic arithmetic as well as advanced mathematical functions while cleanly managing edge cases and preventing runtime crashes.

## ✨ Features
- **Basic Arithmetic:** Addition, subtraction, multiplication, and division with zero-division protection.
- **Advanced Math:** Exponents/powers and square roots.
- **Trigonometry:** Sine, cosine, tangent, cotangent, secant, and cosecant (with automatic degree-to-radian conversion and undefined-value checks).
- **Logarithms:** Natural logarithms with input validation.
- **Factorials:** Efficient calculation using Python's built-in math module.
- **Error Handling:** Gracefully handles invalid choices, negative square roots, and division by zero without crashing.
